Wildberries и Ozon прямо в чате

Подключает ИИ-ассистента напрямую к вашим кабинетам WB и Ozon. Продажи, остатки, цены, финансы, отзывы — приходят из Seller API с указанием источника, а не выдумываются. Два кабинета в двух браузерах превращаются в один разговор обычными словами.

«Сколько я продал на этой неделе?»

Обычный ассистент ответит уверенно и правдоподобно — и назовёт число из воздуха. Спросите его дважды и получите два разных ответа:

412 000≠ 380 500≠ 445 200

Модель не смотрит в кабинет — она достраивает похоже выглядящую цифру. Для решения о закупке или цене на такой цифре опираться нельзя. А браузерные агенты спотыкаются о капчу и авторизацию.

Здесь цифра берётся из ответа Wildberries и Ozon — с методом и полем, из которого она пришла. Не пересказ, не догадка.

Почему это не обёртка вокруг чата

«Подключите AI к продажам» обычно значит чат, который уверенно врёт цифрами или ломается о капчу. Здесь три принципа против этого.

Цифры из Seller API

Продажи, остатки, цены, финансы приходят из ответа Wildberries и Ozon с указанием источника и полей. Не пересказ и не «прикидка» модели.

Safety-гейт перед записью

Прежде чем поменять цену или остаток, агент показывает что именно изменится и просит подтверждение. Случайно «уронить цену втрое» не выйдет.

Без браузера и капчи

Обращение идёт по токену кабинета напрямую в API. Никаких браузерных сценариев, капч и падающих авторизаций. Ключи лежат локально у вас.

Готовые сценарии, а не только сырой API

Внутри 793 метода Seller API обоих кабинетов. Поверх них — пошаговые сценарии под ежедневные задачи продавца: с трактовкой результата и типичными ошибками.

Планировщик дозаказа

Считает дни покрытия по остаткам и продажам и подсказывает, что пора дозаказать, пока не ушло в out-of-stock.

Остатки и скорость продаж — из API, а не на глаз.

Аудит цен

Показывает товары с красным индексом цены на Ozon и сравнивает ваши цены с рынком. Меняет цену только с вашим подтверждением.

Как пользоваться: скажите обычными словами

Запоминать методы не нужно. Опишите задачу по-русски, агент подберёт нужный метод или сценарий и проведёт по шагам, спросив, чего не хватает.

Продажи и сравнение площадок

покажи продажи за неделю на WB и Ozon и сравни сделай ABC-анализ по выручке и покажи товары-хвост

Остатки и закупки

Цены и финансы

какие товары на Ozon с красным индексом цены вытащи финотчёт реализации WB за прошлый месяц

Не уверены, с чего начать

что ты умеешь по моему кабинету собери отзывы ниже 4 звёзд и сгруппируй жалобы

Совет: первым делом скажите «что ты умеешь по моему кабинету» — агент покажет готовые сценарии для WB и Ozon. Несколько магазинов подключаются и переключаются прямо из чата.

Установка

Несколько способов, результат один. От вас нужны только ключи кабинета — зависимости ставятся сами при первом запуске.

Claude Desktop — в один клик

Скачайте .mcpb из GitHub Releases и дважды кликните. Claude Desktop сам поставит расширение и спросит ключи. Без терминала и Gatekeeper. Один бандл поднимает WB + Ozon + Performance сразу.

Попросить своего ИИ — без терминала

Откройте Claude или Cowork и скажите «установи WB + Ozon MCP». Агент проведёт по встроенному скиллу установки. В Claude Code ставится полностью сам.

Для разработчиков — uvx

uvx marketplaces-mcp-ru запускает объединённый сервер прямо из PyPI. Отдельные серверы — командами wb-mcp / ozon-mcp / ozon-perf-mcp. В VS Code и Cursor ставится кнопкой из README.

Docker — без Python на машине

docker run -i --rm -e WB_API_TOKEN=… ghcr.io/ilyautov/marketplaces-mcp-ru — тот же сервер по stdio. Этот образ указан в MCP Registry как OCI-пакет. Для удалённого доступа есть HTTP-режим (MCP_TRANSPORT=http).

Проверка после установки: uvx marketplaces-mcp-ru doctor --live — по каждому маркетплейсу покажет, сколько инструментов загрузилось, найдены ли ключи и отвечает ли кабинет.

Claude Desktop — .mcpb Claude Code / Cowork — родной Codex — mcp add Cursor / VS Code — в один клик Docker — ghcr.io Gemini — GEMINI.md

Где взять ключи: Wildberries — seller.wildberries.ru → Настройки → Доступ к API; Ozon — seller.ozon.ru → Настройки → API-ключи. Ключи хранятся локально (chmod 600), в репозиторий и в чат не попадают.
