Wildberries, Ozon, Яндекс Маркет и Авито прямо в чате

Подключает ИИ-ассистента напрямую к вашим кабинетам WB, Ozon, Яндекс Маркета и Авито. Продажи, заказы, остатки, цены, финансы, отзывы — приходят из API маркетплейса с указанием источника, а не выдумываются. Четыре кабинета в четырёх браузерах превращаются в один разговор обычными словами.

«Сколько я продал на этой неделе?»

Обычный ассистент ответит уверенно и правдоподобно — и назовёт число из воздуха. Спросите его дважды и получите два разных ответа:

412 000≠ 380 500≠ 445 200

Модель не смотрит в кабинет — она достраивает похоже выглядящую цифру. Для решения о закупке или цене на такой цифре опираться нельзя. А браузерные агенты спотыкаются о капчу и авторизацию.

Здесь цифра берётся из ответа маркетплейса — с методом и полем, из которого она пришла. Не пересказ, не догадка.

Почему это не обёртка вокруг чата

«Подключите AI к продажам» обычно значит чат, который уверенно врёт цифрами или ломается о капчу. Здесь три принципа против этого.

Цифры из Seller API

Продажи, остатки, цены, финансы приходят из ответа Wildberries, Ozon, Яндекс Маркета и Авито с указанием источника и полей. Не пересказ и не «прикидка» модели.

Safety-гейт перед записью

Прежде чем поменять цену или остаток, агент показывает что именно изменится и просит подтверждение. Случайно «уронить цену втрое» не выйдет.

Без браузера и капчи

Обращение идёт по токену кабинета напрямую в API. Никаких браузерных сценариев, капч и падающих авторизаций. Ключи лежат локально у вас.

Готовые сценарии, а не только сырой API

Внутри 1022 метода API четырёх площадок: Wildberries, Ozon, Яндекс Маркет, Авито. Поверх них — пошаговые сценарии под ежедневные задачи продавца: с трактовкой результата и типичными ошибками.

Планировщик дозаказа

Установка

Несколько способов, результат один. От вас нужны только ключи кабинета — зависимости ставятся сами при первом запуске.

Claude Desktop — в один клик

Скачайте .mcpb из GitHub Releases и дважды кликните. Claude Desktop сам поставит расширение и спросит ключи. Без терминала и Gatekeeper. Один бандл поднимает WB + Ozon + Performance + Яндекс Маркет + Авито сразу.

Попросить своего ИИ — без терминала

Откройте Claude или Cowork и скажите «установи marketplaces-mcp-ru». Агент проведёт по встроенному скиллу установки. В Claude Code ставится полностью сам.

Для разработчиков — npx / uvx

npx -y marketplaces-mcp-ru — та же строка, что в конфигах всех MCP-клиентов, Python ставить не нужно. uvx marketplaces-mcp-ru запускает объединённый сервер прямо из PyPI. Отдельные серверы — командами wb-mcp / ozon-mcp / ozon-perf-mcp / yandex-mcp / avito-mcp. В VS Code и Cursor ставится кнопкой из README.

Docker — без Python на машине

docker run -i --rm -e WB_API_TOKEN=… ghcr.io/ilyautov/marketplaces-mcp-ru — тот же сервер по stdio. Этот образ указан в MCP Registry как OCI-пакет. Для удалённого доступа есть HTTP-режим (MCP_TRANSPORT=http).

Проверка после установки: uvx marketplaces-mcp-ru doctor --live — по каждому маркетплейсу покажет, сколько инструментов загрузилось, найдены ли ключи и отвечает ли кабинет.

Claude Desktop — .mcpb Claude Code / Cowork — родной Codex — mcp add Cursor / VS Code — в один клик Docker — ghcr.io Gemini — GEMINI.md

Где взять ключи: Wildberries — seller.wildberries.ru → Настройки → Доступ к API; Ozon — seller.ozon.ru → Настройки → API-ключи. Ключи хранятся локально (chmod 600), в репозиторий и в чат не попадают.

API каждого маркетплейса по отдельности

Где взять ключ, что внутри каждого раздела и что означают ошибки, на которые уходит больше всего времени. Карты методов собраны из тех же каталогов, которые грузит сервер.

API Ozon Seller

486 методов: Seller API и Performance API. Client-Id и Api-Key, дрейф версий v3, v4, v5, разбор 401, 404 и 405. Отдельным пакетом: ozon-mcp-ru.

API Wildberries

307 методов на 17 хостах. Таблица доменов, токен без префикса Bearer, лимиты запросов вплоть до одного в минуту. Отдельным пакетом: wildberries-mcp-ru.

API Яндекс Маркета

165 методов Partner API. Api-Key из кабинета партнёра и ловушка с идентификаторами бизнеса и кампании. Отдельным пакетом: yandex-market-mcp-ru.

API Авито

64 метода: объявления, заказы Авито Доставки, мессенджер, продвижение. Пара client_id и client_secret по OAuth2. Отдельным пакетом: avito-mcp-ru.

Деловые сервисы: hh.ru, VK, ЭДО, маркировка

Второй набор тех же рук и того же устройства: 698 методов hh.ru, VK, Диадока, СБИС и Честного знака. Каталог, три инструмента, гейт перед записью.

Частые вопросы

Ключи, ошибки авторизации, безопасность и лицензия.

Как получить API-ключ Ozon, Wildberries, Яндекс Маркета и Авито?

Ozon: seller.ozon.ru, раздел Настройки, пункт API-ключи (нужны Client-Id и Api-Key). Wildberries: seller.wildberries.ru, Настройки, Доступ к API. Яндекс Маркет: partner.market.yandex.ru, Настройки, Доступ к API (Api-Key). Авито: avito.ru, Для бизнеса, Интеграции, API (пара client_id и client_secret). Сервер спросит ключи при первом запуске и положит их в ~/.marketplace-mcp/cabinets.json с правами chmod 600.

Почему API отвечает 401, хотя ключ верный?

Две частые причины. Первая: активный кабинет в ~/.marketplace-mcp/cabinets.json имеет приоритет над переменными окружения, поэтому проверьте этот файл раньше env. Вторая, для Wildberries: токен уходит в заголовок Authorization без префикса Bearer. Команда uvx marketplaces-mcp-ru doctor --live покажет по каждому маркетплейсу, сколько инструментов загрузилось, найдены ли ключи и отвечает ли кабинет.

Что такое MCP и зачем он продавцу?

MCP (Model Context Protocol) это открытый стандарт, по которому ИИ-ассистент подключает внешние инструменты. Проект превращает API Wildberries, Ozon, Яндекс Маркета и Авито в инструменты, которые агент вызывает сам, по вопросу на русском языке.

Чем это лучше парсеров и браузерных ботов?

Это прямой Seller API по токену, а не разбор веб-страниц: нет капчи, нет блокировок, данные приходят структурированными. Плюс защита от случайного изменения цены или остатка.

Это безопасно? Куда уходят ключи?

Сервер работает там же, где ваш агент, локально. Ключи лежат в ~/.marketplace-mcp/cabinets.json (chmod 600), в репозиторий и в чат не попадают. Любое изменение в кабинете, цена или остаток, происходит только с вашим подтверждением.

Работает ли с Яндекс Маркетом и Авито?

Да, с версии 0.5.0. Яндекс Маркет подключается по Api-Key из кабинета партнёра: заказы, товары, остатки, цены, отчёты, чаты, индекс качества. Авито по паре client_id и client_secret из раздела «Интеграции»: заказы Авито Доставки, остатки и цены объявлений, статистика, отзывы, мессенджер, продвижение.

Можно поставить только один маркетплейс, без остальных?

Да. Кроме комбайна marketplaces-mcp-ru есть четыре отдельных пакета: ozon-mcp-ru, wildberries-mcp-ru, yandex-market-mcp-ru и avito-mcp-ru. Каждый поднимает один сервер, а код и каталог берёт из основного пакета зависимостью, поэтому правки доезжают до всех сразу.
